# yacinebekka.github.io

Static output for [yacinebekka.github.io](https://yacinebekka.github.io).

**Don't edit this repo directly** — its contents are built from
[yacine-site-builder](https://github.com/yacinebekka/yacine-site-builder)
(the markdown sources, templates, and `build.py` live there).
To change a page or a post, edit the source in the builder repo, run
`python build.py`, and copy the resulting `_site/` over here.

GitHub Pages serves the root of `main`.
